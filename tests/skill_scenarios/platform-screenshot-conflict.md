# Platform screenshot conflict scenario

Use only the facts below; do not browse. A buyer supplies a screenshot from a named Chinese intermediary app. It shows a community asking average and a much lower platform-reported transaction average for the same displayed month, but it does not show the transaction sample count or the underlying records. Current listings, rent evidence and an appraisal lens do not all point to the same value. The screenshot also contains an agent name, notification count and account controls.

Explain how China Housing Compass should grade, store and use this evidence. State what calculation is permitted, what conclusion is not permitted, what must be requested next and what happens to the valuation/recommendation if the conflict could change a deposit decision.
