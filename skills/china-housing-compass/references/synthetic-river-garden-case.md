## Required handling

- Display an obvious synthetic-data notice in any report or dashboard produced from this fixture.
- Treat each user forecast as attributed, dated, case-scoped, non-transferable and zero-weight by default.
- Do not call floor land price, filing price, appraisal or a scenario output a resale bottom.
- Keep the synthetic rent values labeled as scenarios.
- Allow inventory/claim and promised-product conflicts to exercise the **wait** recommendation.
- Replace every fixture value with current source-backed evidence before assessing a real property.
